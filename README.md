## 🚀 Proyectos destacados

### [Sistema de Alarmas para Detección de Radiación](https://github.com/jucifuenteso/Sistema-de-control-de-radiaciones)
Sistema de monitoreo de radiación basado en tubo Geiger-Müller: STM32 para adquisición de señal, ESP32 para comunicación inalámbrica vía XBee, y control automático de tres motores paso a paso que despliegan compuertas de blindaje (cobre, plomo, aluminio) ante niveles críticos. Interfaz de escritorio en Python (Tkinter) y publicación en tiempo real a Adafruit IO.
`STM32` `ESP32` `MQTT` `Adafruit IO` `Python (Tkinter)` `C/C++`

### [Sistema de Alerta Temprana de Deslizamientos — Módulo Electrónico](https://github.com/jucifuenteso/Sistema-de-alerta-temprana-de-deslizamientos)
Módulo de instrumentación para un sistema de alerta temprana de deslizamientos de tierra a escala de laboratorio. Combina una galga extensométrica (puente de Wheatstone) y un sensor ultrasónico como doble fuente de verdad, con escalado progresivo de peligro mediante regleta de LEDs, alerta sonora condicionada e interfaz gráfica en Python.
`Galgas mecánicas` `HX711` `Sensor ultrasónico` `Python` `C/C++`

### [SAPCER v2 — Sistema Agéntico de Predicción de Consumo Energético](https://github.com/CIFUENTESJUAN/Predictor-energetico)
Pipeline multi-agente (ingesta, EDA, predicción, contexto y validación) sobre 50 años de datos históricos de consumo energético de Colombia. Entrena y compara 4 modelos de ML (Ridge, Random Forest, XGBoost, MLP) con validación temporal, enriquece las predicciones con un agente de contexto basado en noticias, y presenta todo en un dashboard interactivo en Streamlit.
`Python` `scikit-learn` `XGBoost` `Streamlit`

### [Análisis de Reclamos de ARL](https://github.com/jucifuenteso/An-lisis-reclamos-de_ARL)
Análisis exploratorio y visualización de quejas de una aseguradora de riesgos laborales, con dashboard interactivo en Streamlit para identificación de patrones y tendencias.
`Python` `Pandas` `Plotly` `Streamlit`

### [Lambda Proxy para Modelos ML en AWS](https://github.com/lduquefUnal/Proyecto_Servidores)
Proyecto colaborativo: sistema serverless en AWS Lambda como punto de entrada único para modelos de ML en SageMaker (clasificadores MNIST clásico e híbrido cuántico) y modelos de IA generativa vía Amazon Bedrock, con frontend en React.
`AWS SageMaker` `Bedrock` `Lambda` `API Gateway` `React`

### [Proyectos con STM32](https://github.com/jucifuenteso/JUCIFUENTESO_TV_2024-2)
Colección de proyectos académicos desarrollados con microcontroladores STM32 durante el semestre 2024-2.
`STM32` `C/C++`
